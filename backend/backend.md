## Backend starter

`server.js` starts an Express server with a GET endpoint that looks up a Pokémon type through PokéAPI and returns type names for two damage relations:

- **Example URL:** `http://localhost:5001/api/type/fire`
- Replace `fire` with a type name or ID.

Start it from this folder with `npm run dev` (auto-restarts when files change) or `npm start`.
